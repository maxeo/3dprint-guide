# Guide di stampa 3D

Guide HTML di stampa e montaggio dei progetti 3D, pubblicate con GitHub Pages:
https://maxeo.github.io/3dprint-guide/

| Progetto | Guida | Sorgenti (privati) |
|---|---|---|
| Sakura | https://maxeo.github.io/3dprint-guide/sakura/guida.html | [3dprint-sakura](https://github.com/maxeo/3dprint-sakura) |
| Supporto per tablet | https://maxeo.github.io/3dprint-guide/supporto-tablet/guida.html | [3dprint-supporto-tablet](https://github.com/maxeo/3dprint-supporto-tablet) |
| GattoLavello compatto | https://maxeo.github.io/3dprint-guide/gattolavello/guida.html | [3dprint-gattolavello](https://github.com/maxeo/3dprint-gattolavello) |
| SkinkOcchiali | https://maxeo.github.io/3dprint-guide/skinkocchiali/guida.html | [3dprint-skinkocchiali](https://github.com/maxeo/3dprint-skinkocchiali) |
| Organizer modulare | https://maxeo.github.io/3dprint-guide/organizer/guida.html | [3dprint-organizer-modulare](https://github.com/maxeo/3dprint-organizer-modulare) |
| Stand Controller PS5 | https://maxeo.github.io/3dprint-guide/stand-ps5/guida.html | [3dprint-stand-controller-ps5](https://github.com/maxeo/3dprint-stand-controller-ps5) |

I sorgenti dei progetti stanno nei repo privati `3dprint-*`. Le cartelle qui sono copie:
per aggiornarle eseguire `./aggiorna_guide.sh`, poi commit e push.
